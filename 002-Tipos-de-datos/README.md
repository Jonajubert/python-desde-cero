# Python Desde Cero

## Capítulo 002 - Tipos de Datos

Python determina automáticamente el tipo de dato de una variable según el valor que almacena.

## Tipos básicos

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| int | Número entero | 30 |
| float | Número decimal | 1.78 |
| str | Texto | "Hola" |
| bool | Verdadero o falso | True |

## Código

```python
edad = 30
altura = 1.78
nombre = "Jonatan"
trabaja = True
```

## Resultado esperado

```
=== TIPOS DE DATOS ===

Nombre: Jonatan
Edad: 30
Altura: 1.78
¿Trabaja?: True
```
